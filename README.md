---

## 🚀 About The Project
This project is a 2D arcade-style game where the player controls a ball through various environments. The development focused heavily on fine-tuning 2D physics, creating balanced level layouts, and delivering a seamless user experience.

### ✨ Key Features
* **Realistic 2D Physics:** Smooth ball movement with precise gravity, bounciness, and collision detection.
* **Clean 2D Design:** Visually balanced user interface with cohesive color palettes and layouts.
* **Responsive Controls:** Optimized for immediate response to player inputs (Keyboard / Mouse / Touch).
* **Level Management:** A modular system for transitioning smoothly between menus, gameplay levels, and game-over screens.

---

## 🛠️ Tech Stack
* **Game Engine:** Unity Engine
* **Programming Language:** C# (C-Sharp)
* **Physics System:** Unity 2D Physics (Rigidbody2D, CircleCollider2D, PhysicsMaterial2D)

---

## 📂 Project Structure
The `Assets` directory is strictly organized for scalability and clean development:
* `📁 Scripts`: C# scripts governing ball movement, game managers, and UI logic.
* `📁 Sprites`: 2D artwork, textures, backgrounds, and visual assets.
* `📁 Scenes`: Main Menu, Gameplay Levels, and Victory/Defeat screens.
* `📁 Prefabs`: Reusable game objects pre-configured with components and scripts.

---

## 🎮 Getting Started

### Prerequisites
* **Unity Hub** and **Unity Editor** (Version 2022.3 LTS or newer recommended).

### Installation & Setup
1. Clone the repository using Git:
   ```bash
   git clone https://github.com
   ```
2. Open **Unity Hub**.
3. Click **Add** and select the cloned project folder.
4. Once Unity finishes importing the assets, navigate to `Assets/Scenes`, open `MainMenu.unity`, and press **Play**.
